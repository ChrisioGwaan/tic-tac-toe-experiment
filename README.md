# Tic-Tac-Toe Experiment

I came up with this experiment to test my recent research on the Minimax Alpha-Beta pruning algorithm and Monte Carlo Tree Search (MCTS). This experiment is inspired by [Google DeepMind's AlphaGo](https://www.youtube.com/watch?v=WXuK6gekU1Y) in 2015.

## Experiment Introduction

1. Human vs. Minimax Alpha-Beta Pruning
2. Human vs. Monte Carlo Tree Search (MCTS)
3. Minimax Alpha-Beta Pruning vs. Monte Carlo Tree Search (MCTS)
